01

Azka Ilham A.D.P.

X PPLG 4 / 08

Mengerjakan Iklan Milik

Aulya Dinda Mahasti — No. Absen 07

Foto Produk Iklan Aulya Dinda Mahasti

1. Menentukan Variabel

x = harga satuan 1 kipas angin pintar.

y = harga satuan 1 Smart Waste.

2. Membuat Model Matematika

Paket 1: 4x + y = 490.000
Paket 2: x + 3y = 645.000

3. Penyelesaian

4x + y = 490.000 | ×1
x + 3y = 645.000 | ×4

4x + y = 490.000
4x + 12y = 2.580.000
-11y = -2.090.000
y = 190.000

Substitusi:
4x + 190.000 = 490.000
4x = 300.000
x = 75.000
4. Hasil Akhir

Harga kipas angin pintar: Rp75.000

Harga Smart Waste: Rp190.000

5. Refleksi

Saya belajar menggunakan metode eliminasi dan substitusi untuk menentukan harga produk. Kesulitan yang saya alami adalah menghitung angka yang cukup besar. Saya membantu proses perhitungan, berdiskusi, dan bekerja sama dalam menyelesaikan tugas.

02

Hafid Fatahusna Jatmiko

X PPLG 4 / 17

Mengerjakan Iklan Milik

Miftakhul Aulia Ikhsan — No. Absen 27

Foto Produk Iklan Miftakhul Aulia Ikhsan

1. Menentukan Variabel

x = harga satuan 1 Reglow Tree.

y = harga satuan 1 LumiClock.

2. Membuat Model Matematika

Paket 1: 4x + 5y = 410.000
Paket 2: 3x + 4y = 315.000

3. Penyelesaian

4x + 5y = 410.000 | ×4
3x + 4y = 315.000 | ×5

16x + 20y = 1.640.000
15x + 20y = 1.575.000
x = 65.000

Substitusi:
4(65.000) + 5y = 410.000
260.000 + 5y = 410.000
5y = 150.000
y = 30.000
4. Hasil Akhir

Harga Reglow Tree: Rp65.000

Harga LumiClock: Rp30.000

5. Refleksi

Dari kegiatan ini, saya memahami cara menyelesaikan permasalahan menggunakan SPLDV. Kesulitan yang dihadapi adalah menentukan langkah eliminasi dan substitusi dengan benar. Saya berkontribusi dalam perhitungan, memberikan ide, berdiskusi, dan bekerja sama dengan kelompok.

03

Puri Ayu Agustina

X PPLG 4 / 32

Mengerjakan Iklan Milik

Firmansyah Dwi Julia — No. Absen 16

Foto Produk Pengerjaan Puri Ayu Agustina

1. Menentukan Variabel

x = harga satuan 1 kipas angin pintar.

y = harga satuan 1 rak serbaguna dari casing CPU.

2. Membuat Model Matematika

Paket 1: 2x + 3y = 660.000
Paket 2: 5x + 2y = 715.000

3. Penyelesaian

2x + 3y = 660.000 | ×5
5x + 2y = 715.000 | ×2

10x + 15y = 3.300.000
10x + 4y = 1.430.000
11y = 1.870.000
y = 170.000

Substitusi:
2x + 3(170.000) = 660.000
2x + 510.000 = 660.000
2x = 150.000
x = 75.000
4. Hasil Akhir

Harga kipas angin pintar: Rp75.000

Harga rak serbaguna: Rp170.000

5. Refleksi

Melalui tugas ini, saya memahami bahwa SPLDV dapat digunakan untuk menentukan harga dua jenis produk. Kesulitan yang dihadapi adalah proses eliminasi dan substitusi. Saya ikut membantu perhitungan, memberikan ide, dan berdiskusi dalam menyelesaikan tugas kelompok.
